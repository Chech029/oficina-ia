## 2. Respuestas clave dadas

- **MCP** = Model Context Protocol: USB-C para IA; conecta herramientas (filesystem, GitHub, navegador, BD…) de forma estándar. OpenCode (`opencode mcp add`, `/mcps`), dsh (`dsh-mcp-client`), Antigravity (`mcp_config.json`, vacío hoy).
- **Harnesses y modelos free de OpenCode** (doc oficial `/v2/docs/console/harnesses`): los modelos free-tier **solo están disponibles dentro de OpenCode**; cualquier otro harness recibe **403** incluso con API key. Desde otros harnesses solo valen modelos de **pago** o **Go** ($10/mes) vía gateway:
  - Pay-as-you-go: `https://opencode.ai/inference`
  - Go: `https://opencode.ai/inference/go`
  - Path OpenAI Chat Completions: `/openai/v1/chat/completions`
  - Exige header `x-opencode-session: ses_...` (obligatorio en Go).
- **dsh puede apuntar a otros endpoints** vía `cordis.patch.yml` (rutas `openai-completions` + `baseURL` + `apiKeyEnv`). dsh → OpenCode Go sería posible con una `oc_sk_...`, pero **sin probar aún** y **nunca con los free**.
- **dsh → Ollama local** sería trivial (ruta hand-declared `openai-completions`, `baseURL: http://127.0.0.1:11434/v1`, `apiKeyEnv` placeholder). **No aplicado.**
- **Antigravity**: no verificado cómo añadir modelos locales/personalizados (búsqueda web sin resultados; el CLI existe en `~/.gemini/bin/agy`).
